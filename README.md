# 法匪（HOUHI）

**「法匪（HOUHI）」は、法的文書の作成・分析プロセスをAIと連携して革新する、法律実務家のためのリーガルテックツールです。**

従来のWord作成における煩雑な書式設定から解放され、Markdown形式で直感的に裁判文書を作成できます。AI（LLM）との連携を前提に設計されており、証拠分析から戦略立案、起案、そして提出書類のPDF生成までをシームレスに支援します。

## なぜ法匪なのか

1.  **脱Word・Markdown特化**: 裁判所特有の複雑な書式（右寄せ、インデント、表）をシンプルなテキストで管理。レイアウト崩れに悩まされる時間をゼロにします。
2.  **AIネイティブなワークフロー**: 証拠書類などあらゆる情報をテキスト（Markdown）化し、ChatGPTやGeminiなどのLLMが最も理解しやすい形で提供。高度な法的分析や起案を可能にします。
3.  **実務に即したツール群**: 号証スタンプの自動化、相手方書面のテキスト化、証拠管理など、現場の「面倒」を解消する専用機能を搭載しています。

## 弁護士のための実践的ワークフロー

本ツールを使用した、現代的な訴訟活動のフローは以下の通りです。

### STEP 1: 証拠の電子化と分析（一般OCR）
依頼者から受け取った大量の証拠書類（契約書、陳述書、メール履歴、スクショなど）。まずはこれらを電子データとして使える形にします。
- **ツール**: [一般OCR]
- **操作**: PDFや画像をドラッグ＆ドロップ。
- **効果**: 全ての文字情報がテキスト抽出されます。
- **活用**: このテキストをAIに読み込ませ、「時系列表を作って」「契約上のリスクを挙げて」「矛盾点を探して」と指示し、瞬時に分析結果を得られます。

### STEP 2: 戦略立案と大量資料の考察（AIアーカイブ）
事件が複雑化すると、資料が膨大になります。一つずつAIにアップロードするのは非効率です。
- **ツール**: [AIアーカイブ]
- **操作**: 関連する証拠ファイルが入ったフォルダごとドロップ。
- **効果**: AIが読みやすい形式に整形された、単一の巨大なコンテキストファイルが生成されます。
- **活用**: これをChatGPTやGeminiのプロンプトに添付。「フォルダ内の全証拠を踏まえ、被告の主張に対する反論構成案を3つ提案して」といった高度な推論を引き出せます。

### STEP 3: 相手方書面の分析（裁判OCR・ページ結合）
相手方から届いた準備書面や、裁判所の判決文。紙をスキャンしただけのPDFでは検索も引用もできません。
- **ツール**: [裁判OCR] → [ページ結合]
- **操作**: 相手方書面PDFをOCR処理し、分割されたページを結合。
- **効果**: 引用しやすいMarkdownテキストになります。
- **活用**: 「相手方主張の論理的弱点はどこか」「判例との整合性は」とAIと壁打ちし、即座に次回期日の反論骨子を練ることができます。

### STEP 4: 書面の起案（instructions活用）
戦略が決まれば、いよいよ書面の作成です。ゼロから書く必要はありません。
- **活用**: `instructions/` フォルダにある「訴状」「準備書面」などの指示書テンプレートを使用します。
- **操作**: 「STEP 2で作った事実関係を元に、この指示書の形式で訴状を起案して」とAIに指示。
- **効果**: 裁判所提出用の書式に準拠したMarkdownの原案が生成されます。

### STEP 5: 書面の推敲と整理（番号振直）
AIが作った原案を加筆・修正していくと、項番（第1、1、(1)、ア...）がズレることがよくあります。
- **ツール**: [番号振直]
- **操作**: 起案中のMarkdownファイルをドロップ。
- **効果**: 文書全体の項番階層を自動で解析し、正しい連番に振り直します。推敲時のストレスを解消します。

### STEP 6: 完成・提出（PDF変換・号証スタンプ）
最後に、裁判所に提出できる形式に仕上げます。
- **ツール**: [PDF変換], [号証スタンプ], [FAX PDF化]
- **操作**: 完成したMarkdownをPDF変換。証拠PDFにはスタンプ処理。
- **効果**: 美しくレイアウトされた訴状PDFと、右上に赤文字で「甲第〇号証」と連番が入った証拠PDFセットが完成します。必要に応じてFAX送信用に画像化・二値化PDFへ変換できます。

## 主な機能一覧

| ツール名 | 機能概要 | 対応ファイル |
| :--- | :--- | :--- |
| **PDF変換** | Markdown文書を裁判所提出用の美しいPDF（CSS組版）に変換・保存します。 | `.md`, `.html` |
| **一般OCR** | 証拠資料（契約書、陳述書など）を高精度でテキストデータ化します。 | `.pdf`, 画像 |
| **裁判OCR** | 相手方の準備書面や判決文を、引用しやすいMarkdown形式に変換します。 | `.pdf`, 画像 |
| **ページ結合** | OCRで分割された複数のMarkdownファイルを1つに結合します。 | `.md` |
| **番号整理** | 起案中にズレてしまったMarkdownの項番（第1、1、(1)...）を自動修正します。 | `.md` |
| **AIアーカイブ** | 複数の資料を、ChatGPT等のAIに読ませるための1つのテキストファイルにまとめます。 | フォルダ, 複数ファイル |
| **号証スタンプ** | 証拠PDFの右下に、赤文字で「甲第〇号証」を連番で追記します。 | `.pdf` |
| **FAX PDF化** | PDFの全ページを画像化して二値化し、テキスト/フォント情報を含まないFAX送信用PDFを作成します。 | `.pdf` |

## 使い方

本アプリケーションは、原則としてGUI（グラフィカル・ユーザー・インターフェース）で操作します。

### 起動方法
以下のいずれかの方法で起動します。
1. `bin/法匪.exe` をダブルクリック（Windows環境）
2. 開発環境の場合: `npm run gui`

### 操作方法
画面上部のツールバーから機能アイコンを選択し、対象のファイルを画面中央の点線エリア（ドロップゾーン）にドラッグ＆ドロップしてください。
処理結果は、元のファイルと同じ場所に作成される `output/` フォルダ等に保存されます。

## セットアップ

### 必要環境
- Node.js (v16以上推奨)
- インターネット接続（Copper PDF公開サーバーを使用）

### インストール

```bash
npm install
node setup.js
```

**setup.jsの役割**:
- AI指示書の生成（`src/templates`と`src/base/court_doc_rules.md`を結合し、`instructions/`に出力）
- 初期設定ファイルの確認


AI機能やカスタムPDFサーバーを使用する場合は、`config.template.json`を`config.json`にコピーして編集してください：

```json
{
    "gemini": {
        "apiKey": "YOUR_GEMINI_API_KEY",
        "textModel": "gemini-2.0-flash-exp"
    },
    "copper": {
        "serverUri": "ctip://cti.li/",
        "user": "user",
        "password": "kappa"
    }
}
```

## Markdown仕様

詳細な記法は [`Markdown仕様書.md`](Markdown仕様書.md) を参照してください。

### 基本的な記法

**階層構造**:
```markdown
## 第1　請求の趣旨
## 1　被告は、原告に対し...
## (1) 損害の内訳
```

**配置ブロック**:
```markdown
### --右
令和〇年〇月〇日
### --

### --左
〇〇地方裁判所　御中
### --
```

**表形式**:
```markdown
- 訴訟物の価格:1,600,000円
- 貼用印紙額:13,000円
```
