# 裁判文書用Markdown仕様書

本システムでは、標準的なMarkdownをベースに、裁判文書特有の書式（階層構造、右寄せ・左寄せ、表組みなど）を自動変換するための拡張仕様を採用しています。

## 1. 基本書式

### 見出し
- `# タイトル`: 文書中央に配置される大見出し（`<h1>`）となります。原則として文書タイトルにのみ使用します。
- `## 第1 見出し`: 階層構造を持つ見出し。Markdownプレビューでの見栄えを考慮し、`##` を推奨します。
- 通常の文書見出しとして `#` を付ける場合は、階層の深さにかかわらず `##` に統一します。階層は `第1`、`1`、`(1)` などのマーカーで判定されます。
- `附属書類`、`証拠書類`、`別紙事実証明書` などの非番号付きセクションも、文書タイトルでない限り `##` を使います。
- `###` は右寄せ・左寄せ・改ページなどの特殊マーカー用として使い、本文見出しには使いません。

### 目次
- `### 目次`: その位置に目次を生成します。目次は任意です。
- 短い書面や目次が不要な書面では記述しません。
- 目次には第1階層（`第1` など）と第2階層（`1` など）の表題が表示されます。
- 第2階層は、本文そのものを拾わないよう、表題らしく句点 `。` を含まない行だけが目次対象になります。

### 段落
- 通常のテキストは、自動的に1文字インデント（字下げ）され、両端揃えで配置されます。

### 画像
- `![説明文](画像ファイル名.png)`: 画像を中央寄せで挿入します。
- 画像は書面幅を超えない範囲で表示され、常に独立したブロックとして中央配置されます。
- 画像パスは、Markdownファイルから参照できる相対パスを推奨します。

## 2. 階層構造（リーガルナンバリング）

行頭に特定のマーカーを置くことで、自動的にインデントと番号振りが適用されます。Markdownプレビューで見やすくするために、見出し行は `##` を付けます。

| レベル | マーカー例 | 変換後の形式 |
| :--- | :--- | :--- |
| 1 | `第1` | 第1、第2... |
| 2 | `1` | 1、2... |
| 3 | `(1)` | (1)、(2)... |
| 4 | `ア` | ア、イ... |
| 5 | `(ア)` | (ア)、(イ)... |
| 6 | `a` | a、b... |
| 7 | `(a)` | (a)、(b)... |

**記述例:**
```markdown
## 第1 請求の趣旨
## 1 被告は、原告に対し...
## (1) 損害の内訳
```

## 3. 配置ブロック

特定の範囲を右寄せ、または左寄せにします。

### 右寄せブロック（署名・当事者欄など）
`### --右` で開始し、`### --` で終了します。
- ブロック内の各行は、文書全体の「表組み（リスト形式）」の合計幅に合わせて右側に配置されます。これにより、署名欄と事件情報などの幅が統一されます。

```markdown
### --右
〒100-0001
東京都千代田区...
原告　甲野　太郎
### --
```

### 左寄せブロック（事件番号・宛先など）
`### --左` で開始し、`### --` で終了します。
```markdown
### --左
令和○年（ワ）第○○○号
- 被告：乙山　次郎
### --
```

## 4. 表組み（2つのスタイル）

裁判文書の「附属書類」や「事件情報」などに使用します。

### リスト形式（推奨）
Markdownプレビューでも内容が確認しやすく、記述も簡潔です。
`- 項目名：内容` の形式で記述します。
- **グローバル幅調整**: 文書内のすべてのリスト形式テーブル（「附属書類」以外）は、最も長い行に合わせて列幅が自動的に統一されます。

```markdown
- 訴訟物の価格：1,600,000円
- 貼用印紙額：19,500円
```

### パイプ形式
標準的なMarkdownのテーブル記法です。
```markdown
|項目名|内容|
```

### 証拠説明書テーブル
ヘッダー行に「甲号証」または「乙号証」と「標目」が含まれている場合、自動的に証拠説明書用のスタイルが適用されます。
- **セル結合**: 空のセルは自動的に一つ上のセルと結合されます（rowspan）。
- **推奨列構成**:
  1. 甲号証（または乙号証）
  2. 標目
  3. 原本写
  4. 作成年月日
  5. 作成者
  6. 立証趣旨

```markdown
| 甲号証 | 標目 | 原本写 | 作成年月日 | 作成者 | 立証趣旨 |
| :--- | :--- | :---: | :--- | :--- | :--- |
| 1 | 契約書 | 原本 | 令和6年1月1日 | 原告・被告 | 契約の成立 |
| 2-1 | 領収書 | 写し | 令和6年1月2日 | 被告 | 弁済の事実 |
| 2-2 | | 写し | 令和6年1月2日 | | |
```
（上記の例では、甲2-2の標目・作成者・立証趣旨が甲2-1と結合されます）

### 特殊な処理
- **金額の右寄せ**: 2列目の内容が数字や「円」のみの場合、自動的に右寄せされます。
- **附属書類**: 直前の見出しが「附属書類」の場合、自動的に番号振りが適用される専用のスタイルになります。

## 5. 特殊マーカー

### 日付の自動右寄せ
和暦（令和・平成など）または西暦の形式で1行記述すると、自動的に右寄せされます。
- 例: `令和7年1月1日`

### 宛先の自動左寄せ
行末が「御中」または「様」で終わる場合、自動的に左寄せされます。
- 例: `○○地方裁判所 御中`

### 以上（結語）
`以上` とのみ記述された行は、自動的に右寄せされます。

### 改ページ
`### -- 任意のテキスト --` の形式で記述すると、その位置で改ページが挿入されます。
- 例: `### -- 別紙 --`

### 区切り線（点線）
`### ---` と記述すると、その位置に点線の区切り線が挿入されます（改ページはしません）。

### 空行（スペーサー）
`### ...` と記述すると、その位置に空行相当の余白が挿入されます（記号は表示されません）。

### 目次
`### 目次` と記述すると、その位置に自動生成された目次が挿入されます。目次は任意であり、短い書面や目次が不要な書面では記述しません。
- 目次対象は第1階層と第2階層です。
- 第2階層は、句点 `。` を含まない番号行だけが表題として扱われます。

```markdown
### 目次

## 第1　本書面の要旨

## 第2　争点の位置付け及び本件の訴訟構造

1　争点の位置付け

1　本件で裁判所がまず区別すべきなのは、誰が削除請求を行うことができるかという問題である。
```
