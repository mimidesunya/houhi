# 裁判文書用Markdown仕様書

法匪は、Markdownで書いた裁判文書を、裁判所提出用の体裁に変換します。通常のMarkdownを基礎にしつつ、見出し、番号、配置、表、目次などに専用の記法があります。

## 基本方針

- 文書タイトルは `#`、通常の見出しは `##` を使います。
- 見出しの深さは `#` の数ではなく、`第1`、`1`、`(1)` などの番号マーカーで決まります。
- `###` は目次、配置、改ページなどの特殊マーカー専用です。本文見出しには使いません。
- 番号マーカーの後ろは半角スペースにします。
- 通常の説明文は、番号を付けずにそのまま書けます。
- アラビア数字と英字アルファベットは、本文中も含めて半角に統一します。ただし、投稿内容や証拠原文を正確に引用する場合など、元の文字幅自体に意味がある箇所は原文どおりにします。

## インライン装飾

本文、見出し、表セルの一部に下線を付ける場合は、対象部分を `++` で囲みます。

```markdown
本件投稿のうち、++原告の社会的評価を低下させる部分++は次のとおりである。
```

`++` を文字として表示したい場合は、`\++` と書きます。

## 見出しと本文番号

| 用途 | 書き方 | 例 |
| :--- | :--- | :--- |
| 文書タイトル | `#` | `# 準備書面` |
| 通常の見出し | `##` | `## 第1 請求の趣旨` |
| 番号付き見出し | `##` | `## 1 争点の整理` |
| 本文中の番号付き項目 | `##`なし | `1 被告は、原告に対し、金〇〇円を支払え。` |
| 通常本文 | マーカーなし | `原告は、次のとおり主張する。` |

同じ `1 ...` でも、見出しとして立てる場合は `## 1 ...`、本文中の番号付き項目として書く場合は `1 ...` とします。

```markdown
## 第1 請求の趣旨

1 被告は、原告に対し、金〇〇円を支払え。
2 訴訟費用は被告の負担とする。

## 第2 請求の原因

## 1 当事者

原告は、〇〇を業とする者である。
```

## 階層マーカー

| 階層 | マーカー例 |
| :--- | :--- |
| 1 | `第1`、`第2` |
| 2 | `1`、`2` |
| 3 | `(1)`、`(2)` |
| 4 | `ア`、`イ` |
| 5 | `(ア)`、`(イ)` |
| 6 | `a`、`b` |
| 7 | `(a)`、`(b)` |

階層マーカーは、見出しにも本文中の番号付き項目にも使えます。見出しにするか本文項目にするかは、`##` の有無で区別します。

## 目次

`### 目次` と書くと、その位置に目次を生成します。短い書面では不要です。

目次には、主に `## 第1 ...` と `## 1 ...` の見出しが入ります。本文中の番号付き項目を目次に入れたくない場合は、見出し化せず `##` なしで書きます。

```markdown
### 目次

## 第1 事案の概要

## 1 当事者
```

## 配置ブロック

右寄せ又は左寄せにしたい範囲を、開始マーカーと終了マーカーで囲みます。

```markdown
### --右
令和〇年〇月〇日
### --

### --左
〇〇地方裁判所 御中
### --
```

- `### --右`: 右寄せブロックを開始します。
- `### --左`: 左寄せブロックを開始します。
- `### --`: ブロックを終了します。
- ブロック内に空行は入れません。

## 証拠番号

文中で証拠を引用するときは、簡易な証拠番号を全角括弧で囲みます。

- 良い例: `確認メール（甲1）`
- 良い例: `サーバーログ（乙2）`
- 良い例: `領収書（甲3-1）`
- 避ける例: `甲第1号証`、`甲1号証`

証拠ファイル名は、先頭に簡易な証拠番号を置き、アンダースコアで内容を続けます。

- `甲1_確認メール.pdf`
- `乙2_サーバーログ.pdf`
- `甲3-1_領収書.pdf`

証拠説明書の表では、ヘッダーとして `甲号証` 又は `乙号証` を使い、行には `1`、`2-1` のように番号だけを書けます。

## 表

### リスト形式

短い項目表には、リスト形式を使えます。

```markdown
- 訴訟物の価格:1,600,000円
- 貼用印紙額:13,000円
```

`附属書類` や `証拠書類` の下では、専用の番号付き一覧として整形されます。

```markdown
## 附属書類

- 訴状副本:1通
- 証拠説明書:1通
```

### パイプ形式

通常のMarkdownテーブルも使えます。

```markdown
| 項目 | 内容 |
| :--- | :--- |
| 事件名 | 損害賠償請求事件 |
```

### 証拠説明書テーブル

ヘッダーに `甲号証` 又は `乙号証` と `標目` を含む表は、証拠説明書用に整形されます。空セルは上のセルと結合されます。

```markdown
| 甲号証 | 標目 | 原本写 | 作成年月日 | 作成者 | 立証趣旨 |
| :--- | :--- | :---: | :--- | :--- | :--- |
| 1 | 契約書 | 原本 | 令和6年1月1日 | 原告・被告 | 契約の成立 |
| 2-1 | 領収書 | 写し | 令和6年1月2日 | 被告 | 弁済の事実 |
| 2-2 | | 写し | 令和6年1月2日 | | |
```

## 画像

標準のMarkdown画像記法を使います。画像は独立した中央寄せブロックとして表示されます。

```markdown
![説明](images/sample.png)
```

## 特殊マーカー

| 記法 | 機能 |
| :--- | :--- |
| `### 目次` | 目次を挿入 |
| `### -- 任意のテキスト --` | 改ページ |
| `### ---` | 点線の区切り線 |
| `### ...` | 空行相当の余白 |

## 自動整形

- 日付だけの行は右寄せになります。
- `御中` 又は `様` で終わる行は宛先として整形されます。
- `記` だけの行は中央寄せになります。
- `以上` だけの行は右寄せになります。
