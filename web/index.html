法匪 Web

使い方を見る

法匪 Web は、ブラウザで開くだけで使える無料の道具で、インストールも登録も要りません。 書面の起案、PDF への変換と印刷、号証スタンプ、FAX 用 PDF は、すべて開いているブラウザの中で処理するので、書類の中身がどこかのサーバーへ送られることはありません。 ただし、字の形をそろえるためのフォント（Google Fonts）と PDF を扱う部品は、インターネットから読み込みます。

書面は、チャット AI に Markdown で書かせ、ここで体裁を整えて PDF にします。 起案で AI への頼み方をコピーし、できた Markdown を PDF変換 / 印刷に貼り付けると、提出前チェックで【要確認】の残りや号証番号の飛びなどを見たうえで印刷できます。

メール FAX の送信、宛名ラベル、Word への変換、音声の文字起こしは、Windows 用のデスクトップ版で使えます。

起案 書面を選び、Chat AIに渡す引継書をコピーします。 AIアーカイブ 事件資料のMarkdownとテキストを、AIへ渡すZIPにまとめます。 PDF変換 / 印刷 Markdownを貼り付け、紙面を確認して印刷またはPDF保存します。 号証スタンプ PDFや画像の右上に、ファイル名から読んだ号証番号を入れます。 FAX用PDF PDFを並べて結合し、FAX向けの白黒PDFにします。
