Overview

裁判の書類作りを、AIで少し楽にする道具です

本人訴訟では、相手の書面を読む、証拠を整理する、自分の主張を書く、PDFを作る、といった作業を自分で進めます。 法匪 Web は、その中の「読む」「整理する」「下書きする」を ChatGPT、Claude、Gemini などのAIに手伝わせるための道具です。

AIにはMarkdownで書かせます。 Markdownは「# 見出し」「- 箇条書き」のような簡単な記号で、文章の形を分かりやすくする書き方です。 AIはMarkdownを読み書きしやすく、PDF変換もしやすくなります。

訴訟が進むと、相手方や裁判所から紙の書面が届くことがあります。 その紙はPDFにして、mimi-ocr でMarkdownに変えると、AIに読ませやすくなります。

無料のAIだけで、長い裁判記録を読ませたり、書面を何度も直したりするのは厳しいです。 実際には有料プランを使う前提が現実的です。 それでも、弁護士費用と比べれば、調査、整理、下書きの費用を抑えられる可能性があります。

1

起案でAIへの頼み方を作ります。

2

チャットAIにMarkdownの書面案を作らせます。

3

PDF変換 / 印刷でPDFにします。

4

必要なら号証スタンプやFAX用PDFで整えます。

AIアーカイブは、事件の資料をまとめてZIPにする道具です。 ZIPをチャットAIに渡すと、状況整理、争点整理、次に出す書面の相談がしやすくなります。

号証スタンプは、証拠に「甲1」「乙1」のような番号を押す道具です。 FAX用PDFは、FAXで送りやすい白黒PDFを作る道具です。

AIは間違えます。 提出前には、日付、金額、名前、証拠番号、相手の主張を必ず自分で確認してください。 不安なときは、弁護士や法律相談も使いましょう。

記録フォルダの置き方

裁判ごとに1つのフォルダを作ります。 Windowsなら、まずは「ドキュメント」の中に「裁判」フォルダを作るのが分かりやすいです。 中は「日付＋内容」で分けると、後で探しやすくなります。 

C:\Users\ユーザー名\Documents\裁判\2024-01-24-事件名
├─ MEMO.txt
├─ 資料
├─ 2024-01-24-最初の書面
│  ├─ 自分の書面
│  └─ 自分の証拠
├─ 2024-04-19-申立て
├─ 2025-03-05-第1回期日
│  ├─ 自分の書面
│  ├─ 相手の書面
│  └─ 証拠
├─ 2025-06-25-第2回期日
│  ├─ 自分の書面
│  ├─ 相手の書面
│  └─ 証拠
└─ AIアーカイブ用
   └─ 今回AIに読ませる資料

最初は 自分の書面、相手の書面、証拠 くらいに分ければ十分です。 「甲号証」は原告側の証拠、「乙号証」は被告側の証拠です。 スキャンしたPDFとmimi-ocrで作ったMarkdownは、同じ場所に並べて置くと見比べやすくなります。 AIにまとめて読ませるときは、必要なファイルだけを AIアーカイブ用 に集めます。

実務で必要になりやすいもの

  • プリンタ: 裁判所や相手方へ、紙で出す場面があります。
  • ADF付きドキュメントスキャナ: 紙をまとめてPDFにできます。ADFは、紙を1枚ずつ自動で送る機能です。購入する場合は Amazonでドキュメントスキャナを検索 できます。
  • インターネットFAX: FAX機がなくてもPDFを送れます。例として モバイルFAX があります。
  • PDFを扱える環境: PDF保存、印刷、ファイル名の整理をよく使います。

Drafting

起案

  1. 作成したい書面を選びます。
  2. 「引継書をコピー」を押します。
  3. コピーした文章をチャットAIに貼り付けます。
  4. できたMarkdownをPDF変換 / 印刷へ貼り付けます。
起案を開く

AI archive

AIアーカイブ

  1. 事件資料を入れたフォルダ、または .md / .txt ファイルを選びます。
  2. 「ZIP作成」を押します。
  3. ZIPファイルをチャットAIにアップロードします。
  4. 画面右側の指示文もAIに貼り付けます。
AIアーカイブを開く

PDF conversion / print

PDF変換 / 印刷

  1. Markdownを入力欄へ貼り付けるか、.mdファイルを読み込みます。
  2. 「プレビュー更新」で見た目を確認します。
  3. スマホでは横幅に収まります。ピンチアウトで拡大できます。
  4. 「印刷 / PDF保存」で保存します。
PDF変換 / 印刷を開く

Evidence stamp

号証スタンプ

  1. 証拠にしたいPDF、JPG、PNGを選びます。
  2. ファイル名の先頭を「甲1_契約書.pdf」のようにします。
  3. 必要に応じて「全ページに押す」「空白ページを入れない」を選びます。
  4. 「スタンプ」を押して、個別PDFと結合PDFを保存します。
号証スタンプを開く

Fax PDF

FAX用PDF

  1. FAXで送りたいPDFを選びます。
  2. 結合順を確認し、必要なら並べ替えます。
  3. プレビューで白黒の状態を確認します。
  4. 「PDF作成」で保存します。
